❓ Help / Guide
How the CBT application works.
  • Students select their class and enter the correct class password.
  • Questions are randomly selected from the relevant class question bank.
  • SSS 1 contains 10 questions and has 20 minutes.
  • SSS 2 contains 15 questions and has 20 minutes.
  • SSS 3 contains 20 questions and has 30 minutes.
  • Questions that are not answered are counted separately.
  • Every student's result includes the selected answer and correct answer.
  • When Formspree is configured, the complete result is sent online.
  • The teacher's Gmail is included in the submission information.
  • No localStorage, IndexedDB or database is used.
  • The Admin Results table shows results from the current page session only.
  • Formspree can retain submitted results online according to your Formspree account and settings.
